# 🎬 Телеграм-бот для поиска фильмов (Kino Bot)

Telegram-бот на базе библиотеки `pyTelegramBotAPI` (`telebot`), который позволяет быстро находить информацию о фильмах, сериалах и их рейтингах через Kinopoisk API.

---

## 🚀 Основные возможности

* **Поиск фильмов:** Интерактивный поиск кинокартин по названию с отображением постера, года выпуска, рейтинга и описания.
* **Управление состояниями (`FSM`):** Корректная обработка шагов пользователя при вводе названия фильма с возможностью отмены действия.
* **Инлайн-клавиатуры:** Удобные кнопки управления для быстрой навигации и остановки поиска.
* **Система команд:**
    * `/start` — Приветственное сообщение и запуск бота.
    * `/search_films` — Начать поиск фильма.
    * `/help` — Справка по доступным командам.
    * `/stop` — Экстренная отмена текущего поиска и сброс состояний.

---

## 🛠 Технологии и стек

* **Python 3.14**
* **pyTelegramBotAPI** (управление ботом, состояния, фильтры)
* **Requests** (взаимодействие с внешними API)
* **Python-dotenv** (безопасное управление конфигурацией и секретными ключами)
* **Pytest** (юнит-тестирование)

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone <ссылка-на-репозиторий>
   cd Kino_Bot
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   venv\Scripts\activate     # Для Windows
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   В коде проекта (`config.py`) конфигурация считывается через `os.getenv()`. Поскольку файл `.env` не передается через GitHub из соображений безопасности, вам нужно создать его самостоятельно:
   * Создайте файл с именем `.env` в корневой папке проекта.
   * Запишите в него ваши ключи в следующем формате:

   ```env
   BOT_TOKEN=ваш_telegram_бот_токен_сюда
   RAPID_API_KEY=ваш_ключ_kinopoisk_api_сюда
   ```
   *(Файл `.env` защищен с помощью `.gitignore` и никогда не попадет в публичный репозиторий).*

5. **Запустите бота:**
   ```bash
   python main.py
   ```
